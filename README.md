# 🌍 Global Health Dashboard

A responsive web application that fetches and displays global COVID-19 statistics using the disease.sh API.

## ✨ Features

- 🌍 Display global COVID-19 statistics
- 📊 Display total cases, deaths, recovered, active, and critical cases
- 🌎 Display the number of affected countries
- 📈 Display today's cases and deaths
- 🕒 Display the last updated date and time
- 📱 Responsive design
- ⚡ Uses JavaScript async/await
- 🛡️ Handles API errors using try/catch

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🔗 API Used

disease.sh COVID-19 API:  
https://disease.sh/v3/covid-19/all
